# 引き継ぎ: 日本国内ドライブ難易度推定ツール(2月の温泉地巡り)

## ゴール
日本国内のA→Bの車ルートについて、次を返すツールを作る。

- 距離、所要時間、ルートの線(LineString / GeoJSON)
- 2月のレンタカー運転の「難易度スコア」(山道、急勾配、凍結しやすさ、避けた方がいい区間)

用途は個人の旅行計画(非営利)。予算は無料で収めたい。

## 採用する構成
| 役割 | 採用 | 備考 |
|---|---|---|
| ルーティング・道路属性 | **Valhalla**(セルフホスト) | Geofabrikの日本OSM抽出データで構築。`route`と`trace_attributes`を使う |
| 気象・凍結傾向 | **Open-Meteo**(無料枠、APIキー不要) | 過去データAPIで2月の気温・積雪を地点ごとに取得 |
| 標高・勾配の精度向上(任意) | 国土地理院の標高API / DEMタイル | Valhallaの標高タイル(約30m)は山道では粗いため補う。大量取得ならDEMタイルをローカルで引く |

## 処理の流れ
1. Valhallaの`route`でA→Bのルートを取得(距離、時間、polyline6のジオメトリ)。
2. 取得した線を`trace_attributes`に渡し、区間ごとの道路種別、舗装、橋、トンネル、勾配、制限速度を付ける。
3. 線を50〜100mおきにサンプリングし、標高(国土地理院API等)から勾配を再計算して、連続する急坂区間を検出する。
4. 区間ごとに代表点を決め、Open-Meteoの過去データから2月の統計を取る。
   - 最低気温0℃未満の日の割合
   - 積雪深が一定以上の日の割合
   - 気温は道路の実標高に合わせて補正(約0.65℃/100m)する。Open-Meteoの解像度は約9〜11kmで、谷や峠は平均化されるため。
5. 区間ごとにスコア化して、GeoJSON(LineString + 属性とスコア)で出力する。

## スコアの例(叩き台)
次の要素を重み付けして1〜5段階にする。重みは実データを見ながら調整する。

- 標高が高い区間(例: 1,000m超が長く続く)
- 急勾配の連続(例: 8%超)
- 2月の凍結日数が多い、積雪が多い
- 橋、トンネル出入口(路面が先に凍る・状態が急変する)
- 細い道、未舗装(`unclassified`、`track`、`service`など)
- カーブの多さ(LineStringの角度変化から概算)

## Open-Meteoの無料枠(2026-10-08に公式ページで確認)
- 非営利のみ。商用は不可。
- 上限: 1分600回、1時間5,000回、1日10,000回、月300,000回。
- 変数が10個超、または期間が2週間超の場合は1リクエストが複数回分として数えられる(例: 2月を10年分だと1リクエストが十数回分)。
- データはCC BY 4.0なので、クレジット表記が必要。
- 公式: https://open-meteo.com/en/pricing

## 重要な制約・注意
- **路面が実際に凍っているか、通行止め、チェーン規制は、このツールからは分からない。** 出発前は公式の規制情報(各道路管理者、JARTIC等)と道路ライブカメラで確認する。
- 冬季閉鎖が毎年ある道路(例: 志賀草津道路、蔵王エコーライン)は、ルート検索が通してしまうことがある。事前に手動で確認するか、除外区間(`exclude_polygons`)として管理する。
- OSMの`access:conditional`は日本では付与が不完全で、頼らない。
- 日本の山間部ではOSMの速度制限や道幅の属性が欠けやすく、所要時間が実際より短く出がち。
- 橋とトンネルはValhallaのエッジ属性から拾える。日陰・北向き斜面は、進行方位と地形からの推定にとどまり、精度は限定的。
- Valhalla、国土地理院API、Open-Meteoの仕様や制限は変わるため、実装前に公式ドキュメントで確認する。

## 比較の経緯(参考)
- Valhalla vs OSRM: 道路属性(勾配、橋、トンネル、舗装)を取りたいのでValhalla。OSRMは高速な距離・時間計算向き。
- Valhalla vs ORS: 同じOSMデータなら道路網の質は同等。既存の線に属性を後付けする用途と、日本全域のセルフホストの軽さからValhalla。
- Google Routes APIは所要時間の精度が高いが、道路属性が取れず、結果の保存・再利用に制限がある。今回は不採用。

4. Open-Meteoの過去データ取得とキャッシュ(同じ地点を繰り返し叩かない)を追加。
